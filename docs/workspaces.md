# Workspaces

Choose a layout from **Window → Workspaces**. Panel dividers can be dragged, and
panels can be moved or selected as tabs. **Save Changes to this Workspace** keeps
your arrangement; **Reset to Saved Layout** restores the saved arrangement.

## Vertical

**Window → Workspaces → Vertical** (9:16 editing) gives the Program monitor the full
height on the right, beside the Source monitor, Effect Controls and Audio Clip Mixer,
the Project, Media Browser and Effects panels, and the timeline underneath. Command id
`window.workspace.vertical`.

## Vertical CapCut Style

**Window → Workspaces → Vertical CapCut Style** gives portrait editing a full-height Program
monitor on the right. Media, effects and the Source monitor share the upper-left
tab group. Properties, Effect Controls, Live Captions, Text and finishing controls
share the group beside it. The timeline, tools and audio meters sit underneath
these groups, leaving the Program monitor tall while editing.

Neither workspace changes the sequence: set the frame size separately when creating a
portrait video (for example, 1080 × 1920, or **Swap Orientation** in Sequence Settings).

The workspace can also be selected through `ui.menu.invoke` with command id
`window.workspace.verticalcapcutstyle` and empty parameters.
